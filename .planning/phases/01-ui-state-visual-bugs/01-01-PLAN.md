In `MarkerRow.refresh_waveform()` method (line 414-416), the current implementation only calls `self.load_waveform()` without clearing cached state first.

The fix: Clear cached waveform state BEFORE reloading to prevent stale data artifacts.

Update `refresh_waveform()` method to:
```python
def refresh_waveform(self):
    """Refresh waveform display (call after audio generation completes)"""
    # Clear cached state to prevent stale data artifacts
    self.waveform_data = None
    self.audio_duration_ms = 0
    self.waveform_canvas.delete("all")  # Clear canvas immediately
    # Reload fresh waveform data
    self.load_waveform()
```

This ensures:
1. `self.waveform_data` is reset so old data doesn't interfere
2. `self.audio_duration_ms` is reset for accurate duration
3. Canvas is cleared immediately (not waiting for load_waveform's draw)
4. Fresh data is then loaded and drawn

Do NOT modify `load_waveform()` or `draw_waveform()` methods - they already work correctly for initial load.

In `AudioMapperGUI.add_marker_by_type()` method (lines 1163-1183), a new marker is created and the editor is opened, but the selection state is not updated. This causes the editor to appear to open for the new marker but internal state still points to previously selected marker.

The fix: Update selection state to the new marker BEFORE opening the editor.

Locate the `add_marker_by_type()` method and add selection sync after marker creation but before opening editor:

```python
def add_marker_by_type(self, marker_type):
    """Add marker of specific type at current position and open editor"""
    if not self.video_player.is_video_loaded():
        messagebox.showwarning("No Timeline", "Please load a video or create a blank timeline first")
        return

    # Delegate marker creation to marker_manager
    marker_index = self.marker_manager.add_marker_by_type(marker_type)

    if marker_index is None:
        return

    # ADDED: Sync selection state to the new marker before opening editor
    self.marker_selection_manager.select_marker_row(marker_index)

    # Define cancel callback that undoes the add if user cancels
    def on_cancel():
        self.history.undo()

    # Immediately open editor for the new marker
    self.open_marker_editor(self.markers[marker_index], marker_index, on_cancel_callback=on_cancel)

    current_time = self.markers[marker_index]["time_ms"]
    print(f"✓ Added {marker_type} marker at {current_time}ms")
```

Add this single line after `if marker_index is None: return` and before the `on_cancel` function definition:
```python
    self.marker_selection_manager.select_marker_row(marker_index)
```

This ensures:
1. Selection state is synced before editor opens
2. The marker row is visually selected in the list
3. The marker indicator is highlighted on the timeline
4. Internal state matches what the user sees
